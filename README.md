# Shivamogga District Dashboard

A responsive map dashboard for Jal Jeevan Mission, PM-KISAN, PM Awas Yojana and e-Shram in Shivamogga district.

The dashboard uses a light theme and has five tabs: District overview, Jal Jeevan Mission, PM-KISAN, PM Awas Yojana and e-Shram.

Official-source snapshot reviewed 23 October 2026. Reporting periods differ by scheme. Historical periods, incomplete geographic coverage and unreconciled source totals remain labelled beside the relevant figures.
